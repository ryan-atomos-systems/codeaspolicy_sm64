# Archived upstream experiments

This directory preserves the original repository's Python RL experiments, Gym wrappers (`env/`), checkpoints, models, notebooks, and media. `README.upstream.md` is the original README. These files are historical reference and are not maintained, installed, or run by the new scaffold. Their relative paths and dependencies may no longer work after relocation.

Use `src/sm64_policy/` and the root README for new work. Do not install this directory's historical requirements into the maintained harness merely to use the environment API. Two upstream model files are retained for provenance; new training outputs belong under ignored `artifacts/`.
